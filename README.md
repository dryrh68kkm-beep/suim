# กล่องสุ่มขนม (suim)

แอปกล่องสุ่มขนมสำหรับร้านชำ เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม

- **หน้าลูกค้า**: เลือกกล่อง S / M / L แล้วกดสุ่ม ระบบตัดสต็อกให้อัตโนมัติ
- **หลังร้าน**: กดค้างที่หัวข้อ "ลุ้นกล่องสุ่มขนม" 2 วินาที แล้วใส่รหัส (ค่าเริ่มต้น `1234`)
  - สต็อกขนม: เพิ่ม/ลบสินค้า ราคาขาย ต้นทุน จำนวน
  - ตั้งค่ากล่อง: ราคา จำนวนชิ้น มูลค่าขั้นต่ำ เพดานต้นทุน และทดลองสุ่ม
  - ยอดขาย: สรุปยอดและกำไรของวันนี้

ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage) เท่านั้น
